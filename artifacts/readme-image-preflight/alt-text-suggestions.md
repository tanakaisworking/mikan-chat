# Alt Text Suggestions

- `mikan-chat-pack-import`: .mikanchatファイルを追加するチャットパック読み込み画面
- `mikan-chat-scenarios-men-dark`: 男性キャラクターのシナリオを並べたダークモードのホーム画面
- `mikan-chat-recommended-scenarios-light`: 女性キャラクターのおすすめシナリオを並べたライトモードのホーム画面
- `mikan-chat-scenario-detail-dark`: ダークモードで表示した、狐の常連・琥珀のシナリオ紹介画面
- `mikan-chat-profile-settings-light`: 文字サイズ、テーマ、性別、生年、好きなジャンルを変更できる設定画面
- `mikan-chat-story-conversation-dark`: ダークモードで琥珀と会話するチャット画面
- `mikan-chat-story-conversation-light`: mikan chatで、雪村しずくとの物語導入から会話へ進むチャット画面
