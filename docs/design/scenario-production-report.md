## 企画ルール

1. 題名で「誰が」「何をして」「何が一つだけおかしいか」を見せる。
2. 導入の最初の返答で、調べる・保留する・断る・帰るなど複数の行動を選べるようにする。
3. ユーザーの性別、過去、感情、好意を勝手に確定しない。
4. 恐怖、契約、仕事上の立場を使って会話継続を強制しない。
5. 職業道具、時刻、温度、封印、帳簿など、会話に使える具体物を最低三つ置く。
6. 画風をバッチ内・既存作間で重複させない。

## 調査から採用した要素

- 恋愛: 契約、再出発、同居、仕事上の信頼を入口にし、恋愛成立は任意にする。
- お仕事: 見えにくい専門性、引継ぎ、記録、検証、職人の手順を会話の選択へ変える。
- 怪異・ミステリー: ルール、報告書、音声、名簿、未登録資料など、調べられる物証を置く。
- SF: 戦闘より、通信遅延、記憶、保存、翻訳、閉店といった日常業務へ落とす。
- ほのぼの: 動物・食・風呂を、かわいさだけでなく安全確認や仕事の手触りと組み合わせる。

## 画像成果物

## 手動確認が残る項目

- 商用公開前に、生成画像の好み・ブランド適合・偶発的な既存作品類似を人が最終確認する。
- 人気調査は企画材料であり、ランキング入りを保証するものではない。
- 反応データが取れたら、クリック率と初回送信率で題名・導入を再評価する。
