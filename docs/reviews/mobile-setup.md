## 確認結果

- 縦積み: 390 × 844では案内画像、進捗、見出し、2つの接続カード、後回し操作が一列で自然に並び、主要操作が画面内に収まっています。
- スクロール: 768px未満で `main` が `h-dvh` + `overflow-y-auto` となり、画像領域と選択領域の合計が短い画面を超えた場合も画面全体を縦スクロールできます。`body` の `min-width: 320px` と組み合わせても横スクロールは発生しません。
- 文字階層: 案内20px、画面タイトル30px、カード見出し18px、説明14pxに縮小され、390px幅でも日本語が不自然に孤立せず読めます。
- 接続カード: 共通 `ChoiceCard` の `setup` sizeを保ち、モバイルだけ高さ、余白、アイコン、文字を縮小しています。2つのカードで質感と操作状態が一致しています。

- アクセシビリティ: ネイティブbutton、可視フォーカス、可視ラベル、画像alt、現在ステップの `aria-current` を維持しています。
- PC回帰: 1440 × 1024画像を再確認しました。変更は `max-md` 内へ限定され、PCの46.5/53.5列比率、カード高、文字階層、余白は維持されています。
- 共通化・スコープ: `SetupScreen` は配置だけを切り替え、基礎質感は `Brand`、`Button`、`ChoiceCard` に残っています。新たな重複部品やスコープ逸脱はありません。
